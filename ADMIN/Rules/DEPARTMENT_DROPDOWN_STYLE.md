# Department Dropdown Style

This rule is consolidated into the canonical [Department Selection Dropdown](DEPARTMENT_SELECTION_DROPDOWN.md) rule.

All current and future department selectors must use the shared `DepartmentSelector` or `DepartmentMultiSelector` component and follow that rule. Do not create screen-specific department dropdowns, chip selectors, button groups, or alternate selected-state styling.

Display-only department tags are outside this rule and continue to use department colours as defined in [Department Color Tags](DEPARTMENT_COLOR_TAGS.md).
