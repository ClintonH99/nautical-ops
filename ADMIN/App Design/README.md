# App Design

Fonts, colors, button styles, and all visual/design specifications for the app.

Reference this folder when building or fixing anything related to how the app looks.

- `BUTTON_TAG_STANDARD.md` defines published/list preview cards and their actions.
- `ACTION_WORDING_STANDARD.md` defines page titles and action wording for create, edit, publish, multi-step, modal, and destructive flows.
